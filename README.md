# Astro Tutorial

Astro를 학습하며 블로그를 만들어 보는 연습 저장소입니다.

Markdown 기반의 정적 블로그를 먼저 완성하고, 이후 API 연동과 임베딩 기반 검색으로 확장하는 것을 목표로 합니다.

## 학습 목표

- [ ] Astro 프로젝트 생성 및 개발 환경 구성
- [ ] 파일 기반 라우팅 이해
- [ ] 컴포넌트와 공통 레이아웃 구성
- [ ] Markdown과 Content Collections로 게시글 관리
- [ ] 게시글 목록 및 상세 페이지 구현
- [ ] Quiet Form 디자인 시스템 적용
- [ ] 정적 사이트 빌드 및 배포

## 확장 목표

- [ ] 태그별 게시글 분류
- [ ] 목차, RSS, 사이트맵 추가
- [ ] 서버 API 연동
- [ ] 임베딩 기반 의미 검색 구현
